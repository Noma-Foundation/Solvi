
The app is called Solvi, inspired by the word “resolve.” It is a request management system, similar to an ITSM (IT Service Management) platform, designed for managing support 
and customer service tickets.

Solvi is part of a larger ecosystem of solutions. It works in conjunction with OrderRequester, a portal that allows customers to submit orders, request quotes, or request services
from a company and track the status of their requests. While OrderRequester is the customer-facing interface, Solvi centralizes the management of these requests,
allowing teams to organize, track, and resolve them efficiently.


### Installation

To install it, you need a stable version of Python, along with the PostgreSQL database (version 18 or higher). In addition, you need Node.js to run the project build.

#### Usage in development mode

```bash
python main.py --dev
```

#### Usage in production mode

```bash
python main.py
```
