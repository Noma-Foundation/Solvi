Remove a callback from an event or remove the entire event.

js.callback(eventName, callback)

Remove a callback from an event or remove the entire event.

Parameters

  1. eventName {String}

    • The name of the event to modify or remove.

  2. callback=null {function() | Object | null}Optional

    • The specific callback to remove. If omitted, the entire event is removed.

Returns

If callback is omitted (or null) the whole event (all callbacks) will be removed. When a specific callback is supplied, the function removes only that callback from the array of callbacks associated with eventName. If no callbacks remain the event is removed.

const eb = new EventBus(); const cb = () => {}; const register = eb.subscribe('my-event', cb); register(); // register the callback eb.unsubscribe('my-event', cb); // removes the specific callback eb.unsubscribe('my-event'); // removes the event entirely
