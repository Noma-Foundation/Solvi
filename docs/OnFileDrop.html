OnFileDrop

  • function
 

OnFileDrop listens to drag and drop events and calls the callback with the coordinates of the drop and an array of path strings.

js.OnFileDrop(callback, useDropTarget)

OnFileDrop listens to drag and drop events and calls the callback with the coordinates of the drop and an array of path strings.

Parameters

  1. callback {OnFileDropCallback}

    • Callback for OnFileDrop returns a slice of file path strings when a drop is finished.

  2. useDropTarget=true {boolean}Optional

    • Only call the callback when the drop finished on an element that has the drop target style. (--wails-drop-target)
